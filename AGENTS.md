# Documentation

There are a few useful links that can be consulted for more information on
deploying a UCSC Genome Browser mirror:
- [Genome Browser in the Cloud User's Guide](https://genome.ucsc.edu/goldenPath/help/gbic.html) - This
  role is built on top of (and dependent on) the Genome Browser in the Cloud
  (GBiC) tool, which is a script that automates the setup of a UCSC Genome
  Browser mirror. This link provides detailed information on how the GBiC tool
  works. 
- [Manual Installation of the UCSC Genome Browser on a UNIX server](https://genome.ucsc.edu/goldenPath/help/mirrorManual.html) - Although
  it has been superseded by the Docker image and the GBIC installation bash
  script, it serves as a reference on how the installation script is
  structured and helps workingg with the configuration files once the Genome
  Browser is running. It is worth taking a look for further developing this role.
